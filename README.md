# React Weather App

A modern weather application built with React and Bootstrap that provides real-time weather information using the OpenWeather API.

## Live Demo

https://react-weather-app-steel-three.vercel.app/

## Features

- Search weather by city name
- Real-time temperature data
- Weather condition and icon
- Humidity information
- Wind speed information
- Feels-like temperature
- Min/Max temperature
- Dynamic background based on weather
- Loading state
- Error handling for invalid cities
- Responsive Bootstrap UI

## Technologies Used

- React.js
- JavaScript (ES6+)
- Bootstrap 5
- OpenWeather API
- Fetch API
- Vite
